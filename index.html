Rclone Personal

Rclone Personal is a private, non-commercial integration used to access my own Google Drive files from my Linux computer through rclone.

Purpose

The application uses the Google Drive API to list, read, create, update, and manage files in my own Google Drive account.

Privacy Policy

This application is intended exclusively for personal use. It does not collect analytics, transmit Google user data to third parties, or operate an external data collection server. Authentication credentials and cached files are handled locally by rclone on my computer.

Data Access

Google Drive permissions are used solely to perform file operations explicitly initiated by the account owner. Access can be revoked at any time through Google Account settings.

Contact

For inquiries, contact the application owner using the support email provided on the Google OAuth consent screen.
